## GATT读取通道测试

连接诊断 → 实时通道测试 → GATT直接读取（30秒）。
保持App前台等待30秒，结束后再次打开连接诊断并复制结果。
测试只发送一次原启动指令，确认后标准读取FFE1，不发送3032，不反复启动采样。
区分空值、固定启动确认、原始值变化和可识别完整数据帧。
不把未知原始值猜成电阻，也不拼接重复属性读取来伪造新样本。
尚未确认实时采集和硬件停止能力。结束接收只结束客户端监听，不代表硬件已停止采样。
原60秒通知监听测试保留在同一测试菜单内。
