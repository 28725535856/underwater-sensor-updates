# 水下传感器应用更新

当前版本：1.0.7（8），Android 6 及以上，实时通道诊断版。

App 更新清单：https://raw.githubusercontent.com/28725535856/underwater-sensor-updates/main/updates/latest.json

从原1.0.6（7）可优先下载约225KB差异包；基包不匹配时下载完整APK。
下载后仍需点击安装更新，并完成Android系统确认。

## 保持连接测试

进入“连接诊断”，点击“保持连接测试”，保持App前台等待60秒。
本测试只发送现有启动命令，确认后继续监听传感器通知；不自动反复启动或发送读取命令。
有效主动数据帧可显示最近一帧，重复帧单独计数；尚未确认硬件停止指令。
“结束接收”只结束客户端监听，不代表硬件已停止采样。
测试结束后复制连接诊断用于联调，诊断不会自动上传。

此仓库仅发布安装包、差异包和更新信息，不包含客户端源码、签名私钥或测量数据。
