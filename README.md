# 水下传感器应用更新

当前版本：1.0.12（13），Android6及以上。

App更新清单：https://raw.githubusercontent.com/28725535856/underwater-sensor-updates/main/updates/latest.json

本版减少刷新停顿，每轮程序固定等待从1.75秒降至0.30秒，实际刷新还包含硬件响应与传输时间。

保留120万Ω软件上限、ADC255超量程、连续趋势连线和真实数据导出。段间有采集间隙，连线仅表示趋势。

开始后保持App前台，停止后查看或导出本次记录。从1.0.10/1.0.11可直接差异升级。

安装完成后确认当前版本1.0.12（13）。63项相关测试与签名、差异重建校验通过；手机刷新效果待验证。

本仓库仅发布APK、差异包和版本说明。
