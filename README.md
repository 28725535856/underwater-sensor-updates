# 水下传感器应用更新

当前版本：1.0.11（12），Android6及以上。

App更新清单：https://raw.githubusercontent.com/28725535856/underwater-sensor-updates/main/updates/latest.json

曲线按实际时间连续连接真实采样点。段间连线表示趋势，采集间隙未消失，Excel不新增数据。

软件显示上限1.2MΩ；ADC255标为超量程。70kΩ等高阻值在原始ADC有效时正常显示。

开始后自动短时采集与读取，红色停止结束App循环；停止后查看记录和导出Excel。检测时保持前台。

从1.0.9或1.0.10可直接差异升级，下载后完成系统安装确认，并核对当前版本1.0.11（12）。

本仓库只发布APK、差异包和版本说明。
