## 使用方法

点击开始检测，按钮变为红色停止检测。App自动执行短时采集和读取，数值及曲线根据新返回的数据更新。
检测时保持App前台；进入后台会结束本次App检测，并保留已接收数据。
点击停止后，数据读取查看本次已保存记录，导出Excel保存整次数据。
自动短测各段之间有通信间隙，图表分段显示，不能作为无间断采样记录。
段内0.5秒是原客户端约定，Excel明确记录段号、时间来源、原始ADC和阻值。
停止结束App接收与自动循环，未定义或发送硬件停止命令。
