# 水下传感器应用更新

当前版本1.1.1（17），无需烧录。

更新清单：https://raw.githubusercontent.com/28725535856/underwater-sensor-updates/main/updates/latest.json

无需烧录，恢复自动采集并改为FIFO逐点显示：收到一批真实数据先入队，按原固件约500ms采样间隔逐点刷新数值和曲线。显示缓存点数；队列空时等待，不补点。取消批间额外等待，避免过早读取空包；停止时发送原读取指令并保留记录，导出包含尚未显示的已采集点。保留蓝牙兼容、120万Ω显示和ADC255超量程。此版本是缓存逐点展示，原固件仍分批回传，不能消除采集与传输延迟。

测试及签名、增量还原通过，手机效果待实测。
