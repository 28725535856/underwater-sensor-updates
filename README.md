# 水下传感器应用更新

当前版本：1.0.10（11），Android 6及以上。

App更新清单：https://raw.githubusercontent.com/28725535856/underwater-sensor-updates/main/updates/latest.json

电阻显示上限提高至1.2MΩ；ADC255标为超量程，不能当作有效阻值。约70kΩ在原始ADC有效时正常显示。

点击开始检测后自动短时采集与读取，红色停止结束App循环；停止后查看记录、导出Excel。段间有间隙，检测时保持前台。

从1.0.9可优先下载约281KB差异包，下载后完成系统安装确认。79项测试与签名、差异还原校验通过；硬件采样范围未改变。

本仓库只发布APK、差异包和版本说明。
